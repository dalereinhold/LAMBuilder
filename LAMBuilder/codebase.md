#  Folder structure
```
LAMBuilder/
│
├── index.html
├── src/
│   ├── app.js
│   ├── ui.js
│   ├── exporter.js
│   └── styles.css
```
#  File descriptions
- `index.html`: The main HTML file that serves as the entry point for the application.
- `src/app.js`: Contains the core application logic and state management.
- `src/ui.js`: Handles the user interface rendering and interactions.
- `src/exporter.js`: Manages the export functionality, converting the app state to Lua code.
- `src/styles.css`: Defines the styles and layout for the application.
